# Security Policy

## Scope
HookForge simulates webhook delivery locally. It does not probe external endpoints or send traffic to third-party receivers.

## Reporting
Do not open a public issue for a real secret or vulnerability that exposes sensitive information. For this portfolio sample, contact the repository owner privately through the contact method in the profile.

## Demo-data rule
Only synthetic or non-sensitive data belongs in this repository. Never commit tokens, credentials, customer records, or private production payloads.
